# 特別料金表ビルダー

お客様ごとの「特別料金ご提案書」を、入力するだけで作成できるブラウザアプリです。
インストール・ビルド不要。`index.html` をブラウザで開くだけで動きます。


## 使い方

1. `index.html`（または1枚で動く `dist/特別料金表ビルダー.html`）をダブルクリック（またはブラウザにドラッグ＆ドロップ）して開く
2. 左パネルの項目を入力すると、右のプレビューが即座に更新される
3. **PDF / 印刷** ボタン → 送信先を「PDFに保存」
   - 用紙: 横向き
   - 余白: **なし**
   - **背景のグラフィック: ON**
   にすると、余白なしのスライド型PDF（1ページ = 1スライド）が出力されます
4. **HTMLで書き出し** を押すと、そのまま送付できる単体HTMLファイルを保存できます

入力内容はブラウザに自動保存されます（同じPC・同じブラウザなら次回もそのまま）。
別のPCへ持ち出すときは **入力内容を保存** でJSONを書き出し、**入力内容を読込** で復元します。

## 入力項目

| 区分 | 項目 |
| --- | --- |
| 基本情報 | 会社名 / 先方名 / 特別プラン名 / 申込期日 / 契約開始時期 / 表紙文言 / 提案元 / 背景文 |
| 自社雇用コスト | 採用経費 / 給料報酬 / 側面経費 / 雇用リスク項目 |
| 基本プラン表 | ページ見出し / 前置きの一文 / 各プランの名称・月額・期間 / 推奨プランの指定（追加・削除可） |
| プランA〜D | 有効・無効 / プラン名 / 副題 / 入れるユニット / ユニットごとの料金・支援期間・人数 / 通常価格 / 一括特別価格 / おすすめ表示（プラン副題・体制キャッチ・構成メモ・組織図の補足・プラン説明文は自動生成、上書きも可） |
| 導入フロー | STEP 1〜4 の項目名・時期・説明 |
| ページ構成 | 出力するページの ON / OFF |
| ユニットマスタ | 各ユニットの標準料金・標準期間・標準人数・役割・説明・実施内容 |

### Dプランを使わない場合

「6. プランD」の **このプランを料金表に表示する** のチェックを外すと、
料金表・組織図・詳細ページから完全に除外されます（A〜Cプランも同様に切り替え可）。

## 自動計算されるもの

- **特別月額** = 選択したユニットの料金合計（手入力で上書き可）
- **支援期間** = ユニットの支援期間の最大値（手入力で上書き可）
- **分割総額** = Σ（ユニット料金 × そのユニットの支援期間）
- **一括特別価格** = 分割総額 − 1ヶ月分（手入力で上書き可）
- **お得額** = 分割総額 − 一括特別価格
- **総稼働リソース** = ユニット人数の合計
- **基本プラン表の総額** = 月額 × 期間（推奨プランは黒＋オレンジで強調）
- **三角形組織図** = 人数の少ない順に上から積み上げ
- **実施内容** = 選択ユニットの提供機能をすべて統合（重複は自動排除）
- **プラン副題**（詳細ページの題名）= 1ユニットなら役割そのまま、2ユニットなら「◯◯＋◯◯」、3つ以上はフィールドワークを含めば「フルスペック実行支援」、含まなければ「Nユニット統合支援」
- **体制キャッチ** = フィールドワークを含めば「全国現場実行完結」、マネジメント代行を含めば「マネジメント連動」、1ユニットなら「単独機能特化」…と構成から判定
- **組織図の補足** = 三角形の上から下の順に役割をつなげた文（例「運用管理の代行から全国現地での実動までの3層体制」）
- **プラン説明文** = 下位プランを含む場合は「◯◯プランの全支援機能に加え、（差分の役割）まで対応する上位プランです。」＋構成に応じた一文
- **構成メモ** = 2ユニットまではユニット名と人数、3ユニット以上は「Nユニット構成 / 総稼働 X名」
- **料金表の機能欄** = 下位プランを含む場合は「◯◯プランの全支援機能」＋差分を自動表示
- **★マーク** = 下位プランから増えた機能（差分が6項目以内のとき）

金額はすべて「万円」単位で入力します（例: 12.5 → 12.5万円）。

## 出力されるページ

1. 表紙
2. 特別ご提案の背景と趣旨
3. 自社で社員を1名採用・雇用する場合の実態（コスト・リスク）
4. 導入プラン別 組織図
5. 料金プラン（アイドマ・ホールディングスの基本プラン表）
6. 【特別料金表】プラン別機能・価格比較（自社雇用との比較付き）
7. 各プランの詳細（有効なプランの数だけ）
8. ご契約から稼働・成果創出までのフロー
9. 最終ページ（申込期日の再掲）

文字量が多い場合は、はみ出さないように文字サイズ・列数・表示件数が自動調整され、
省略した分は「ほか N項目」と表示されます。

## ファイル構成

```
index.html                      アプリ本体（UIとスライドのスタイル）
assets/units.js                 ユニットマスタ（名称・標準料金・標準人数・実施内容）
assets/app.js                   入力フォーム・自動計算・スライド生成・書き出し
dist/特別料金表ビルダー.html    上記3ファイルを1枚にまとめた配布用（./build.sh で再生成）
build.sh                        dist/ を生成するスクリプト
```

配布・持ち運びは `dist/特別料金表ビルダー.html` だけで完結します。
`assets/` を編集したら `./build.sh` を実行して dist を更新してください。

自動生成される文章は、各ユニットの **役割**（短い名詞句）と **説明**（一文）から組み立てています。
言い回しを変えたいときは「10. ユニットマスタ編集」か `assets/units.js` の `role` / `desc` を直してください。
プラン側の5項目（プラン副題・体制キャッチ・構成メモ・組織図の補足・プラン説明文）は、空欄のままなら常に自動、
文章を入力するとその内容が優先されます（消して空欄に戻せば自動に戻ります）。

ユニットや実施内容を恒久的に追加・変更したい場合は `assets/units.js` を編集してください
（アプリ内の「ユニットマスタ編集」はそのブラウザにのみ保存されます）。
