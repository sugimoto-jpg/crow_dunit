# アイドマ営業クエスト ⚔️

営業マン向けの RPG 型教育 Web アプリです。PC ブラウザとスマートフォンの両方で動作します。
アイドマ学園で「虎の巻」を学び、全7大業界の魔物（見込み顧客）と3フェーズの商談バトルで戦い、村人から伝説の勇者を目指します。

## 起動方法

```bash
npm install
npm run dev        # http://localhost:5173 （--host 付きなので同一LANのスマホからもアクセス可）
npm run build      # 型チェック + 本番ビルド
```

## 技術スタック

| 分野 | 採用技術 |
| --- | --- |
| フレームワーク | Vite + React 19 + TypeScript |
| スタイリング | Tailwind CSS v4 / lucide-react |
| 3D | Three.js（純粋な Canvas 実装・プロシージャル生成） |
| 状態管理 | Zustand + persist（LocalStorage に進行状況を永続化） |
| 音響 | Web Audio API による 8bit チップチューン合成（外部音声アセットなし） |

## 画面構成

- **アイドマ学園**：虎の巻3講義（冒頭5秒の心理学／「検討します」の深掘り法／伴走型内製化支援の価値）。スライドはスワイプで送れ、最後の確認問題に正解すると EXP と G を獲得できます。Lv.2 でギルドが解放されます。
- **冒険者ギルド**：7業界14件の討伐依頼。業界ごとにタブを切り替えられ、難易度は初級〜魔王級。推奨Lv−1 から受注でき、討伐済みの依頼は報酬半減で再戦できます。
- **営業バトル**：Phase1 業界動向フック → Phase2 深掘りヒアリング → Phase3 解決価値提案。
  - 正解時：黄金スラッシュ＋ダメージ＋「なぜ刺さるのか」解説。フェーズ内の初回正解は会心の一撃になります。
  - 不正解時：自キャラが被弾し、顧客の反発セリフと「失注リスク」解説が出ます。
  - 補助：職業スキル（誤答消去・インサイト表示）と回復薬（50G）。
- **勇者・転職**：3Dビューア（ドラッグ/スワイプで360°回転、ピンチ/ホイールでズーム）とリュウ／セリナの切り替え、転職の神殿。

## 職業

| Lv | 職業 | スタイル | 主な特性 |
| --- | --- | --- | --- |
| 1 | 村人 | 見習い営業 | 営業カバン |
| 2 | 戦士 | 突破型 | 剣と盾、HP・攻撃UP |
| 2 | 弓使い | 事前調査型 | 弓、誤答消去×2 |
| 2 | 魔法使い | データ論理型 | 杖、ヒント常時表示 |
| 4 | 聖騎士 | 大手信頼型 | 大盾、被ダメ大幅軽減 |
| 6 | ドラゴンナイト | 大型コンペ型 | ランスと翼 |
| 7 | 伝説の勇者 | 全能エグゼクティブ | 聖剣・王冠・全能力 |

## ディレクトリ

```
src/
  data/        型定義・職業・講義・業界・レベル表・クエスト（業界別ファイル）
  store/       Zustand ストア（LocalStorage 永続化）
  audio/       Web Audio 効果音・BGM シーケンサー
  three/       Stage（レンダラ/入力）・HeroModel・MonsterModel
  components/  HUD・ナビ・モーダル・3Dラッパー
  screens/     学園・ギルド・バトル・勇者画面
```

クエストを追加するには、`src/data/quests/*.ts` に `Quest` 型のオブジェクトを追加します（3フェーズ × 4択、正解は1つ）。
