# 転生魔法学院譚 〜村人から始まる魔王討伐〜

トラックに轢かれて異世界に転生した主人公が、辺境の村の **村人 Lv1** から始まり、
**王立アルカナ魔法学院** に通ってレベルを上げ、**冒険者ギルド** で稼ぎ、
やがて **魔王** に挑むブラウザRPGです。

依存ライブラリはありません。

## 遊ぶには

**1ファイル完結版（おすすめ）**

```bash
npm run build      # dist/tensei-arcana.html を生成
```

生成された `dist/tensei-arcana.html` は単体で動きます。保存してダブルクリックすれば
ブラウザで開いて遊べます。スマホに送って開いても同じように遊べます。

**開発中のファイルのまま開く**

```bash
open index.html                  # そのまま開く
python3 -m http.server 8000      # サーバ経由 → http://localhost:8000
```

進行状況はブラウザの localStorage に自動保存されます。1ファイル版でも
`file://` で開いた状態でセーブ・ロードできることを確認しています
（`ENTRY=dist/tensei-arcana.html FILE=1 node tools/smoke.js`）。

## 遊び方

### 1日は 3 AP

| 行動 | 消費 | 効果 |
|---|---|---|
| 授業を受ける | 1 AP | 科目の習熟度が上がり、能力が永続的に伸び、経験値も入る |
| 図書館で自習 | 1 AP | 全科目の習熟度が少しずつ上がる（経験値なし） |
| 訓練場で鍛える | 1 AP | パーティ全員が経験値を得て、MPが回復する |
| ギルドの依頼 | 1〜2 AP | 戦闘。ゴールドと経験値、戦利品が手に入る |
| 休む | 残り全部 | HP・MPが全回復して翌日へ |

### 学院：15日ごとに学期末試験

- **全6科目**（魔術理論・剣術実習・神聖学・錬金術・魔物学・体術）の**平均習熟度**が合格ラインを超えれば進級。
- 受験には**学費の納入**が必要。払えなければ受験できないので、ギルドで稼ぐことになります。
- 不合格なら留年（同じ学期をやり直し）。
- **3学年 × 3学期 = 9学期**を突破すると卒業。卒業時に聖剣と勇者の証が贈られ、魔王領が解禁されます。
- 科目の習熟度が100に達すると「首席」の称号と専用スキルを習得します。

### ジョブ：全25職の4段階ツリー

```
村人 ─┬─ 魔術師見習い ─┬─ 魔道士 ──── 大魔道士 ──┬─ 賢者
      │                └─ 精霊術師 ── 精霊王の巫子 ┘
      ├─ 剣士見習い ───┬─ 剣士 ────── 魔法剣士 ──┬─ 剣聖
      │                └─ 重騎士 ───── 聖騎士 ────┘
      ├─ 神官見習い ───┬─ 僧侶 ─────── 司祭 ─────┬─ 聖者
      │                └─ 祓魔師 ────── 審問官 ───┘
      └─ 斥候見習い ───┬─ 盗賊 ─────── 忍者 ─────┬─ 影皇
                       └─ 狩人 ─────── 狙撃手 ───┘
```

- 転職できるのは **Lv5 / Lv15 / Lv30 / Lv50** のタイミング。
- **選択は積み重なります**。振り続けた剣は剣聖の形になり、覚えた技は転職しても失われません。
- 魔法剣士・聖騎士は複数の系統から到達できます。

### ギルド：F級からS級まで

昇格には **累計依頼数** と **レベル** の両方が必要で、節目には昇格試験（ボス戦）があります。

| 階級 | 必要レベル | 必要依頼数 | 昇格試験 |
|---|---|---|---|
| E級 | 7 | 3 | ゴブリンロード |
| D級 | 12 | 6 | ― |
| C級 | 19 | 10 | 遺跡の守護者 |
| B級 | 27 | 15 | ― |
| A級 | 36 | 21 | 沼のヒュドラ |
| S級 | 45 | 28 | 紅蓮竜イグナート |

階級が上がると店の品揃えも良くなります。

### 難易度

ゲーム開始時に選びます（あとから変更はできません）。

| 難易度 | 敵のHP | 敵の攻撃力 |
|---|---|---|
| やさしい | 78% | 78% |
| ふつう | 100% | 100% |
| むずかしい | 135% | 122% |

後述のバランス調整はすべて「ふつう」を基準にしています。

### キャラクター

キャラクターはすべて**インラインSVG**で描いています。外部画像は配信時にブロックされるため、
1ファイルに収まるベクター描画にしてあります（拡大しても粗くなりません）。

- 体を脚・胴・頭・後ろ腕・前腕・武器のパーツに分け、CSSで動かす
- **待機・歩行・攻撃・詠唱・被弾・戦闘不能**の動きがある
- 見た目は**ジョブの系統**（村人・魔術師・剣士・神官・斥候）で変わり、
  上位職になるとマントや光をまとう
- **装備中の武器の形**（剣・杖・錫杖・短刀・弓・棒）が手元に反映される
- 同じ系統でも仲間ごとに服の色を変えてあるので見分けがつく
- 転職画面では、**就いたときの見た目を選ぶ前に確認**できる

敵は13種類の型（スライム・獣・小鬼・巨漢・骸骨・飛行・虫・植物・石像・
術者・幽霊・竜・魔族・魔王）を配色違いで使い分けています。

### 移動

拠点・学院・ギルド・街・魔王城には、それぞれの背景とパーティの立ち姿が出ます。
場所を移るときは歩いて向かう演出が入ります（タップで飛ばせます）。

### 戦闘

ターン制のコマンドバトル。最大4人パーティ。横視点で、味方は手前、敵は奥に並びます。

- **属性**（火・水・風・土・光・闇）：弱点を突くと1.6倍、耐性があると0.5倍。
- **状態異常**：毒・火傷・睡眠・麻痺・沈黙・暗闇。
- **バフ／デバフ**：能力の上下、挑発、回避上昇など。
- 全滅しても終わりではありませんが、**所持金の2割を失い、その日は行動できなくなります**。

## 開発・検証

数値バランスは勘ではなく、**実際の戦闘エンジンを回して測定**しながら調整しています。

```bash
node tools/lint-text.js        # 日本語テキストへの異物混入を検出
node tools/test-rules.js       # ルールの境界条件を検証（学費未納・留年・装備中の売却など）
node tools/balance.js          # 進行度ごとの勝率を多数回試行で測る
node tools/diag.js             # パーティ火力と敵の耐久を突き合わせる
node tools/measure-party.js    # パーティ火力曲線を実測して JSON に保存
node tools/retune-enemies.js   # その曲線から敵の数値を設計して書き戻す
node tools/playthrough.js      # 開始から魔王討伐まで自動で通しプレイする
node tools/smoke.js            # 実ブラウザで序盤を操作し JS エラーを検出
node tools/smoke-late.js       # 実ブラウザで卒業〜エンディングまでを確認
node tools/build-single.js     # CSSとJSを流し込んだ1ファイル版を生成
node tools/shots-tour.js       # 主要画面をまとめて撮る（見た目の確認用）
```

`npm test` で lint・ルール検証・ブラウザ操作の確認をまとめて実行します。

ブラウザ検証には Playwright を使います（環境に同梱の Chromium を利用するため
ブラウザのダウンロードは不要です）。

```bash
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install
```

### 敵ステータスの設計方針

`src/data/enemies.js` の数値は `tools/retune-enemies.js` が生成しています。
手で調整するのではなく、次の目標から逆算しています。

- **通常戦**は 1戦あたり約2.6ラウンド（瞬間火力基準）で決着する
- **ボス戦**は節目ごとに 3.0〜9.0ラウンド（真魔王が最長）
- 敵の攻撃は **1ラウンドでパーティ総HPの何割を削るか** で決める
- 全体攻撃を持つ敵は実効火力が数倍になるため、スキル構成から期待値を求めて補正する
- 硬い敵ほど戦闘が長引くので、1ラウンドの圧力を下げて総被ダメージを一定に保つ

敵ごとの「相対的な硬さ・強さ」は `tools/enemy-weights.json` に固定してあり、
再生成しても設計意図が失われないようにしています。

## ファイル構成

```
index.html              画面の骨組みと読み込み順
assets/style.css        スタイル
src/data/               スキル・ジョブ・アイテム・敵・依頼・学院・物語
src/core/
  util.js               乱数などの共通処理
  character.js          成長・転職・装備
  state.js              ゲーム状態とセーブ/ロード
  world.js              暦・学院・ギルド・店
  battle.js             戦闘エンジン（描画から独立した純ロジック）
src/ui/
  sprites.js            キャラクターと背景のSVG描画
  screen_*.js           画面ごとの描画と操作
src/main.js             起動とストーリー進行
tools/                  検証・バランス調整ツール
dist/                   1ファイル完結版の出力先（build で生成）
```

戦闘エンジンは描画から完全に独立しているため、`tools/` から直接呼び出して
何万回でもシミュレートできます。バランス調整はすべてこの仕組みで行っています。
