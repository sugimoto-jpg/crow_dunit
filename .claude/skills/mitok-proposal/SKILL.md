# MiTok 提案書（PowerPoint）作成スキル

顧客ごとのプロンプト（入力情報）を受け取り、**決まった型の提案書 .pptx（約26枚）**を作る。
見本：`proposals/mirai-sekkei_mitok_proposal.pptx`（株式会社みらい設計・訪問マッサージ事業）。
参考実装：`reference/build.js`（スライド生成）、`reference/thumbs/render.js`・`chars.js`（サムネイル生成。キャラクター：daughter/mother・staff・elder・teacher・child）。
2社目の見本：`proposals/clover-house_mitok_proposal.pptx`（教育・子育て／規制が薄い業種は16枚目を「発信ガイドライン」に置換した例）。

## 目的（毎回ブレさせないこと）
- 「無料3本を作って様子見」の姿勢を崩し、**単なる動画制作ではなく事業成長の戦略**だと示す。
- 2回目商談では**料金は出さない**。ヒアリングで数値を取り → 目標値シミュレーション → **次回お打ち合わせ（試算確定・正式提案）→ ご契約**へつなげる。

## 手順
1. **セットアップ**（コンテナは毎回まっさら）：
   `bash .claude/skills/mitok-proposal/reference/setup.sh <scratchpad>/mitok`
   → 依存インストール、日本語フォント導入、LibreOffice Impress 導入、参考スクリプトのコピーまで行う。
2. **入力の読み込み**：プロンプトの顧客情報・文字起こしから、対象事業・ターゲット・強み・約束事項・決裁者（役職）を整理する。「不明」の項目は**仮説として扱い、ヒアリング項目に回す**（捏造しない）。
3. **業界の下調べ（頭の中で）**：紹介元・意思決定者・チャネル・**広告規制**（医療・あはき・不動産・金融・士業など）を確認し、スライドとサムネイル文言に反映する。
4. **サムネイル生成**：`thumbs/render.js` の文言・キャラクター・配色を顧客向けに書き換え、`node render.js` で7枚のPNG（youtube / instagram / tiktok / story1〜4）を出力。**必ず画像を開いて目視確認**（文字切れ・重なり）。
5. **スライド生成**：`build.js` の各スライドの文言を顧客向けに書き換え（構成・レイアウト・ヘルパーは流用）、`node build.js <出力.pptx>`。
6. **QA**（pptxスキルの手順）：`validate.py` → PDF化 → `pdftoppm` で全ページ画像化 → 全ページ目視。はみ出し・重なり・フッター衝突を直して再レンダリング。
7. **納品**：`proposals/<顧客ローマ字>_mitok_proposal.pptx` と `proposals/assets/<顧客>/` にPNGを保存 → `SendUserFile` で送付 → コミット＆push。チャットでは構成と「仮置きの数値・要確認箇所」を簡潔に伝える。

## 守るルール（ユーザーのフィードバック由来）
- **料金表・プラン価格のスライドは作らない。**「課金」「別紙お見積り」等の文言も入れない。
- 「本日ご決定」ではなく「早期ご決定」、契約の起点は「ご契約時」。クロージングは**次回お打ち合わせ**に置く。
- シミュレーション・機会損失の数値は**仮置きと明記**し、スピーカーノートに計算ロジックを書く。
- **営業担当者用メモ（進行、切り返し、決裁者の注意）はスライドに載せず、スピーカーノートへ。**
- 決裁者が代表でない場合（会長・部長など）は、ノートに「決裁フローを冒頭で確認」と必ず書く。
- サムネイル・絵コンテは写真風にしない（フラットなイラスト）。アカウント名・再生時間は「仮」と注記。顧客から写真・ロゴがあれば差し込む。
- 規制業種は、サムネイル・台本の文言にも注記（例：医療保険に触れる場合「医師の同意が必要です」）。効果の断定表現は使わない。

## デザイン
- 16:9ワイド（13.33×7.5in）。フォント「Meiryo UI」（pptx内）、サムネイルは Noto Sans JP／Zen Maru Gothic。
- 配色は**業界に合わせて1色を主色に**（見本：介護＝深緑 `1F5E5B`＋オレンジ `E07B39`）。`build.js` 冒頭の `C` を差し替える。サムネイル側の色も合わせる。
- 表紙と最後はダーク、中身は白背景。アクセントバーや見出し下線は使わない。アイコンは円の中に入れる。

## ハマりどころ
- `pptxgenjs` はグローバルに無い → setup.sh でスクラッチにインストール。
- ChromiumはGoogle FontsのCSSを証明書エラーで読めない → フォントは `~/.fonts` にローカル導入（setup.sh済）。
- LibreOfficeにImpressが入っていないとPDF化が「source file could not be loaded」で失敗 → setup.sh で導入。
- 表（addTable）は日本語の折り返しで行が伸びる。下の要素と重なりやすいので行高と配置に余裕を持たせ、必ず画像で確認。
- `git push` が403の場合はGitHub連携（Claude GitHub App）の問題。ユーザーに連携設定を案内し、ファイルは SendUserFile で先に渡す。
