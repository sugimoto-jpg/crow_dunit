## 1. まず試せること：ホーム画面に追加する（費用0円・今すぐ）

`dist/pwa/` フォルダをどこかに公開すれば、**それだけでアプリのように遊べます。**

- ブラウザの枠が出ない
- 縦画面に固定される
- **一度開けば、通信を切っても遊べる**
- ホーム画面にアイコンが並ぶ

### 公開のしかた（無料の例）

GitHub Pages を使う場合：

```
1. `dist/pwa/` の中身をリポジトリの docs/ か gh-pages ブランチに置く
2. GitHub の Settings → Pages で公開先を指定する
3. 表示されたURLをスマートフォンで開く
4. 共有メニュー →「ホーム画面に追加」
```

> ⚠ **必ず https:// で公開してください。** http:// ではオフライン機能が働きません。
> GitHub Pages は自動で https になります。

**ストアに出す前に、この形で実際に遊んでみることを強くおすすめします。**
指の届きやすさや文字の大きさは、実機で触ってみないと分かりません。

## 2. Androidアプリ（APK）を作る

### 必要なもの

| もの | 備考 |
|---|---|
| Android Studio | 無料。Windows / Mac / Linux で動く |
| Java (JDK 21) | Android Studio に同梱 |

### 手順

```bash
# 1. 最新の内容をアプリに反映する
npm run cap:sync

# 2. Android Studio で開く
npx cap open android
```

Android Studio が開いたら：

```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

できた APK を端末に入れれば、**そのまま遊べます**。

### ⚠ 公開前に必ず変更が必要なもの

`capacitor.config.json` の **appId** は仮の値です。

```json
"appId": "com.example.tenseiarcana"
```

**`com.example.*` はストアで受け付けられません。**
お持ちのドメインを逆にした形（例：`jp.co.○○○.tenseiarcana`）に変更してください。
ドメインをお持ちでない場合も、**他と重複しない固有の文字列**であれば構いません。

変更したら：

```bash
npx cap sync android
```

> **この変更は、ご本人の判断が必要なため私では行いません。**
> 一度ストアに出すと、appId は二度と変更できません。

## 3. iOSアプリを作る（Mac が必要）

```bash
npx cap add ios
npm run cap:sync
npx cap open ios
```

Xcode が開くので、署名を設定してビルドします。

> **Mac と Xcode がなければ、iOS版は作れません。**
> これは Apple の制約で、回避する方法はありません。

## 5. アプリ版で自動的に行われること

ブラウザ版では何も起きず、アプリとして動いたときだけ働きます。

| 動作 | 理由 |
|---|---|
| **保存先を端末の正式な領域に移す** | アプリ内のブラウザ領域は、空き容量が減るとOSに消されることがある |
| **以前のデータを引き継ぐ** | アプリ化する前に遊んでいた記録を失わないため |
| **戻るボタンをゲームにつなぐ** | 何も起きないとアプリが即終了してしまう |
| **他のアプリに切り替えたら保存** | 戻ってきたときに続きから遊べる |
| **攻撃が当たったら短く振動** | 手応え。審査で「アプリらしさ」の材料にもなる |
| **起動画面を絵が出てから消す** | 時間で消すと一瞬まっさらな画面が見える |
| **オフラインの仕組みは登録しない** | 古い内容を抱えて、更新が届かなくなるのを防ぐ |

これらは `src/native.js` にまとまっています。

## 6. 開発の流れ

```bash
npm test              # 16項目の検査（毎回これを通す）
npm run build:pwa     # dist/pwa/ を作り直す
npm run cap:sync      # アプリ側に反映
npx cap open android  # Android Studio で開く
```

ゲームを直したときは `npm run cap:sync` を実行すれば、
アプリ側にも反映されます。**アプリのコードを触る必要はありません。**

## 7. 注意点

### 開発用のパッケージに軽微な警告があります

`npm audit` で3件（moderate）出ますが、いずれも
**アプリを作るときだけ使う道具**（`@capacitor/cli` が使う `xcode` → `uuid`）で、
**配布されるアプリの中には入りません。**

### Androidプロジェクトは作り直せます

`android/` フォルダは `npx cap add android` で再生成できます。
うまくいかなくなったら、消して作り直して構いません。
**ただし、appId の変更と AndroidManifest.xml の縦画面固定は入れ直しが必要です。**
