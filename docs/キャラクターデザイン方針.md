# キャラクターデザインの方針（参考資料をもとに）

> いただいた参考資料と、いまのゲームの描画を突き合わせた結果です。
> **この時点ではコードを変更していません。**

---

## 1. いまのキャラクターを一覧にしました

比較のため、ゲームと同じ方法で全25職・全32体を描き出しました。

- `dist/sprites-jobs.png` … 全25職
- `dist/sprites-enemies.png` … 全32体
- 生成ツール：`npm run sprites`

### ★ そこで分かった一番の問題

> **転職しても、見た目がほとんど変わりません。**

いまの仕組みは「**5系統 × 段階 × 装備武器**」で描いています。
そのため、同じ系統の6職は**ほぼ同じ絵**になります。

| 系統 | 該当する職 | 見た目の違い |
|---|---|---|
| 剣士系 | 剣士見習い → 剣士 → 重騎士 → 魔法剣士 → 聖騎士 → 剣聖 | **ほぼ無し**（Tier4に光の輪が付くのみ） |
| 魔術系 | 魔術師見習い → … → 賢者 | **ほぼ無し** |
| 神官系 | 神官見習い → … → 聖者 | **ほぼ無し** |
| 斥候系 | 斥候見習い → … → 影皇 | **ほぼ無し** |

**25職を用意しているのに、見た目は実質5種類です。**

転職はこのゲームの中心的な楽しみです。
「**強くなった／変わった**」という手応えが、見た目から伝わっていません。
いただいた参考資料は、まさにここを埋める内容でした。

### 敵は比較的よくできています

32体を14種類の形（スライム／獣／小鬼／骨／竜／悪魔など）＋配色で
描き分けており、一覧で見ても区別がつきます。

ただし次の点は改善余地があります。

- 「氷結の魔女」と「四天王・氷刃のセレス」が**同じ絵**
- 「荒野の狼」が獣型で、狼というより猫に見える
- ボスは**大きさと光の輪だけ**の違い

## 2. 参考資料から取り入れられること

| 参考資料の要素 | いまの状態 | 取り入れ方 |
|---|---|---|
| **職業ごとの固有シルエット** | 5系統のみ | **★最優先**。25職それぞれに特徴を付ける |
| **系統ごとの色分け**（赤=近接／緑=弓／紫=魔法／白=回復／茶=特殊） | 5色あるが整理されていない | 参考資料の分類をそのまま採用できる |
| **男女の描き分け** | **無し**（性別の概念が無い） | 名前入力時に選べるようにする |
| **武器の種類**（剣・斧・槍・弓・杖・短剣） | 装備の `shape` で既に対応 | **すでに土台あり**。職業ごとの標準武器を足す |
| **戦闘モーション**（職業別の攻撃演出） | 物理／詠唱の2種類 | 系統ごとに分ける |
| **背景・マップ12種** | 5種類 | **STEP 9 の8エリアとほぼ一致**。連動させる |
| **NPC 20種** | 文字のみ（教師・店主など） | 後回し可 |
| **キャラクタープロフィール** | 仲間3人に設定あり、画面に出していない | ステータス画面に追加できる |

## 3. 実現方法は2つあります

### 方式A：いまのSVG描画を作り込む（容量 0 バイト）

いまと同じ「コードで図形を描く」方式のまま、職業ごとの作り分けを増やします。

| 項目 | 内容 |
|---|---|
| 容量の増加 | **0 バイト**（コードなので） |
| ダウンロード版 | **1ファイルのまま** |
| 権利の問題 | **無し**（自分で描いたもの） |
| 見た目 | シンプルな図形。**参考資料のような絵にはなりません** |
| 作業量 | 職業ごとのパーツを足す。中程度 |
| アニメーション | **いまの28種の動きがそのまま使える** |

### 方式B：画像素材に差し替える

参考資料のような絵を用意して、画像として表示します。

**容量を計算しました（音源と違い、こちらは現実的です）。**

| 入れるもの | 追加容量 | ビルド後 |
|---|---|---|
| 職業25枚（WebP 128px） | +171 KB | 446 KB（現在の1.6倍） |
| 職業 男女50枚 | +343 KB | 618 KB（2.2倍） |
| 職業男女＋敵（82枚） | +562 KB | 837 KB（3.0倍） |
| 全部（114枚） | +781 KB | **1.0 MB（3.8倍）** |

> **BGMは7MB必要で断念しましたが、画像は1MB以内に収まります。**
> ダウンロード版の手軽さを保ったまま実現できます。

| 項目 | 内容 |
|---|---|
| 容量の増加 | +171 KB 〜 +781 KB |
| 見た目 | **参考資料のような絵にできる** |
| 必要なもの | **絵そのもの**（生成・購入・委託のいずれか） |
| 権利 | **要確認**（4章） |
| アニメーション | **作り直しが必要**（画像は変形させにくい） |

## 4. ★ 権利について（重要）

いただいた参考資料は、**AIで生成された画像と思われます**。

ストアで公開する場合、次の点の確認が必要です。

- **その画像を商用利用できるか**（生成に使ったサービスの規約）
- 他の作品の意匠に似すぎていないか
- 第三者の素材が含まれていないか

**参考資料をそのままゲームに入れることは、おすすめしません。**
理由は2つです。

1. 権利関係が不明確なまま公開すると、後から取り下げになる恐れがあります
2. **そのままでは使えません**。ゲーム用の絵には
   「背景が透明」「大きさが揃っている」「向きが揃っている」ことが必要で、
   参考資料は一覧図として作られているため、この条件を満たしていません

> **参考資料は「方向性の指針」として使い、
> 実際に使う絵は改めて用意する**のが安全です。

**ルール10に従い、素材の購入や外部サービスの利用は私の判断では行いません。**

## 5. おすすめの進めかた

> ### **まず方式A、構造は方式Bに移せる形で。**

これは STEP 11（音）で採った考え方と同じです。

```
キャラの見た目を「表」で管理する
  ・いま     … SVGで描く指示（0バイト）
  ・あとで   … 画像ファイル（表を書き換えるだけ）
```

こうしておけば、**絵が用意できた時点で、表を差し替えるだけ**で
方式Bに移れます。ゲーム側のコードは変わりません。

### 理由

1. **いますぐ見た目が良くなります**（絵の準備を待たずに済む）
2. 容量が増えません
3. 権利の問題がありません
4. **絵を用意したあと、無駄になりません**
5. いまの28種のアニメーションがそのまま活きます

## 6. 方式Aで具体的にやること

### 6-1. 職業ごとの見た目（25職）

いまの「5系統」に、**職業ごとの特徴**を足します。

| 要素 | 内容 |
|---|---|
| **頭** | 兜／フード／法冠／ずきん／髪型 など |
| **体** | 鎧／ローブ／法衣／軽装。上位職ほど装飾を足す |
| **肩・背** | マント／肩当て／背中の武器 |
| **標準武器** | 職業ごとに決める（装備で上書き可能） |
| **色** | 参考資料の系統色を採用 |
| **特殊** | 上位職に固有の印（聖騎士の翼、影皇の影 など） |

**例：剣士系6職の描き分け**

| 職業 | 頭 | 体 | 武器 | 特徴 |
|---|---|---|---|---|
| 剣士見習い | 無帽 | 革の胴着 | 短めの剣 | 素朴 |
| 剣士 | 鉢金 | 鎖帷子 | 剣 | |
| 重騎士 | 全身兜 | 板金鎧 | 大剣＋盾 | **体を一回り大きく** |
| 魔法剣士 | 頭巾 | 軽鎧＋外套 | 剣＋魔法陣 | 紫の差し色 |
| 聖騎士 | 羽根付き兜 | 白銀の鎧 | 剣＋盾 | 金の装飾 |
| 剣聖 | 鉢巻 | 道着風 | 太刀 | **光のオーラ** |

### 6-2. 男女の描き分け

参考資料にならい、各職業に男女2種類を用意します。

- 名前を決める画面で選べるようにする
- 仲間3人（リィナ・ヴェルト・ノア）は固定
- **セーブデータに1項目追加**（STEP 10 の移行の仕組みが必要）

### 6-3. 敵の改善

- 「氷結の魔女」と「四天王・氷刃のセレス」を描き分ける
- 狼を獣型から専用の形にする
- ボスに**固有の飾り**（角・王冠・翼など）を足す

## 7. 作業の順序（案）

| 段階 | 内容 | 確認方法 |
|---|---|---|
| 1 | 見た目を「表」で管理する形に変える（**見た目は変えない**） | 一覧画像が同じであること |
| 2 | 系統の色を参考資料に合わせる | 一覧画像で確認 |
| 3 | 剣士系6職を描き分ける（**お手本**） | 一覧画像で確認 |
| 4 | 残り3系統を描き分ける | 一覧画像で確認 |
| 5 | 男女の描き分け（STEP 10 の後） | 一覧画像で確認 |
| 6 | 敵とボスの改善 | 一覧画像で確認 |

**各段階で `npm run sprites` を実行し、一覧画像で確認できます。**
「変えたつもりが別の職まで変わっていた」を防げます。

## 9. 正直に申し上げること

**方式Aでは、参考資料のような絵にはなりません。**

参考資料は、陰影も質感もある描き込まれた立ち絵です。
いまの仕組みは、丸と四角を組み合わせた簡素な図形です。
作り分けを増やしても、**方向性は「シンプルで見やすい絵」のままです**。

それでも方式Aを推す理由は、
**「25職あるのに見た目が5種類」という一番大きな問題は、方式Aで解決できる**からです。

本格的な絵は、**絵の準備が整ってから**、
表を差し替えることで後から実現できます。
