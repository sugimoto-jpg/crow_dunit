## 4. ★ 検査で守られていないこと（正直に）

**これを把握していることが、検査そのものと同じくらい大事です。**

| 守られていないこと | 影響 |
|---|---|
| **Chromium 以外のブラウザ** | **iPhoneのSafariは未検証**。実機確認が必要 |
| **実機のスマートフォン** | 画面サイズを合わせた測定のみ。Safariのアドレスバーによる高さ変化は再現できない |
| **セーブの互換性** | 古いセーブが読めるかのテストが無い（STEP 10 未実装のため） |
| **やさしい／むずかしい の通しプレイ** | → 5章。**むずかしいで問題を発見** |
| **乱数の揺れ** | 通しプレイは1回きり。同じ結果になる保証はない |
| **長時間プレイ** | 40往復＋戦闘10回まで。数時間のプレイは未検証 |
| **音・設定・探索** | 未実装のため検査もなし |
| 見た目の良し悪し | 「変わっていないか」は検査するが「美しいか」は判断できない |

## 5. ★ STEP 15 で見つかった重大な問題

### 5-1. 「むずかしい」の序盤が成立していません

3つの難易度で通しプレイを実行しました。

| 難易度 | 結果 |
|---|---|
| やさしい | ✅ 136日で卒業 → **真魔王撃破（Lv72）** |
| ふつう | ✅ 136日で卒業 → 真魔王戦へ到達 |
| **むずかしい** | ❌ **400日回しても卒業できず。全滅516回** |

原因を戦闘シミュレータで特定しました。

| 場面 | ふつう | むずかしい |
|---|---|---|
| Lv1 単騎 vs スライム×1 | 100% | 81% |
| **Lv2 vs スライム×3（F級の最初の依頼）** | **71%** | **8%** |
| **Lv3 vs 大ネズミ×3（F級依頼）** | **91%** | **14%** |
| Lv4 vs ゴブリン×2 | 100% | 89% |
| Lv15 vs コボルト×2+蝙蝠 | 99% | 59% |
| Lv20 昇格試験 遺跡の守護者 | 96% | 46% |
| Lv50 vs 門番ガルヴァス | 93% | 36% |
| Lv62 vs 真魔王 | 73% | 30% |

**中盤以降（36〜60%）は「むずかしい」として妥当**です。
問題は**序盤だけ**で、Lv2〜3 の最初の依頼が **8〜14%** しか勝てません。

> **「むずかしい」を選んだ人は、ゲーム開始直後に詰みます。**
> 自動プレイが516回全滅したのは、これが理由です。

現在の補正は **敵HP 135% ／ 敵攻撃 122%** です。
序盤はレベルが低く装備も無いため、攻撃力の補正が致命的に効きます。

**ご指示のルール4（ゲームバランスを勝手に変更しない）に従い、
私の判断では変更していません。** 対応案と実測値は 8 章に記載します。

### 5-2. 「ふつう」でも真魔王に負けることがあります

通しプレイを2回実行したところ、1回目は勝利（Lv68）、2回目は敗北（Lv66）でした。
シミュレータでの勝率は **73%** です。

**これは不具合ではありません。**最終ボスとして妥当な難度です。
ただし「必ず勝てる」わけではないことは記録しておきます。


**音（STEP 11）と自由探索（STEP 9）は、公開後でも足せます。**

### ①について：3案を実際に測りました

**ゲームのデータは変更していません。**測定ツール側で値を差し替えて勝率を測りました。

| 場面 | ふつう | **いま**<br>HP135/攻122 | **案A**<br>HP125/攻112 | **案B**<br>HP135/攻112 |
|---|---|---|---|---|
| **Lv2 スライム×3（最初の依頼）** | 71% | **8%** | **53%** | 32% |
| **Lv3 大ネズミ×3（F級依頼）** | 91% | **14%** | **54%** | 38% |
| Lv4 ゴブリン×2 | 100% | 89% | 99% | 99% |
| Lv15 コボルト×2+蝙蝠 | 99% | 59% | 80% | 71% |
| Lv20 昇格試験 遺跡の守護者 | 96% | 46% | 69% | 57% |
| Lv50 門番ガルヴァス | 93% | 36% | 61% | 49% |
| **Lv62 真魔王** | 73% | 30% | 47% | 41% |

- **案A**（敵HP125%・攻撃112%）… 序盤が **8% → 53%** に回復。終盤も 47% でふつう(73%)より明確に難しい
- **案B**（敵HPは据え置き、攻撃だけ112%）… 終盤の歯応えは残るが、序盤は **32%** とまだ厳しい
- **案C**（そのまま）… 「むずかしい」を選んだ人が開始直後に離脱する

**私の推奨は案Aです。**理由：

- 序盤の壁が解消し、**最初の依頼が「勝てるが油断できない」水準**になる
- 終盤の真魔王は 47%。ふつうの 73% と比べて**十分に難しい**
- **序盤が弱いのは補正の掛かり方の問題**（低レベルではHPが薄く、攻撃補正が致命的に効く）なので、値を緩めるのが素直な対処

**ルール4に従い、ご指示をいただいてから実施します。**
変更後は同じ測定をすぐ回せるので、結果をお見せできます。

## 9. 結論

**Phase 0 の目的は達成しました。**

> いま動いているゲームを壊さず、
> **壊れたら気づける状態**にできました。

Phase 0 で作った最大の資産は、機能ではなく**検査の仕組み**です。

- データや計算が意図せず変わったら → **照合が止めます**
- 見た目が意図せず変わったら → **185通りの照合が止めます**
- 例外でゲームが固まったら → **28項目の検査が止めます**
- 名前が衝突したら → **検査が止めます**
- 設計の一方向性が崩れたら → **検査が止めます**

これがあるため、**Phase 1 以降は安心して大きく手を入れられます。**

そして STEP 15 で、**「むずかしい」が遊べない**という
公開前に見つかってよかった問題を1件発見しました。
