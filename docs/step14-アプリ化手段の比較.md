| 項目 | 内容 |

## 4. ★ Apple の審査基準 4.2 について（正確に）

Capacitor を選ぶ場合、これが最大の論点です。**正確にお伝えします。**

### 基準の内容

Apple の審査ガイドライン **4.2（最低限の機能）** は、
おおむね次のことを求めています。

> アプリは、単にWebサイトを包み直しただけのものであってはならない。
> App として十分な機能・内容・体験を備えている必要がある。

### 何が拒否されやすいか

| 拒否されやすい | 通りやすい |
|---|---|
| 中身が**外部のURLを表示するだけ** | 中身が**端末内に入っている** |
| **通信しないと何もできない** | **オフラインで完全に動く** |
| Webサイトと**まったく同じ** | アプリとして**成立している** |
| 内容が薄い | **十分な遊びの量がある** |

### このゲームの立ち位置

| 条件 | このゲーム |
|---|---|
| 外部URLを読みに行くか | **いいえ**（すべて端末内） |
| オフラインで動くか | **はい**（通信機能が無い） |
| 内容の量 | 25職・88スキル・32体の敵・3年分の物語 |
| ゲームとして成立しているか | **はい** |

> **「Webサイトを包んだだけ」には当たらないと考えられます。**

ただし、**審査はAppleの判断であり、保証はできません。**
落ちる可能性はゼロではありません。

### 通りやすくするためにできること

| 対策 | 状況 |
|---|---|
| すべて端末内に入れる | Capacitorの既定の動作。**問題なし** |
| オフラインで完全に動く | **すでに達成済み** |
| 端末の機能を使う（振動・画面の向き固定など） | **追加が望ましい** |
| Webサイト版と差をつける | 必要なら検討 |
| ブラウザらしさを消す（アドレスバー等が見えない） | Capacitorでは元々見えない |

**「端末の振動（触覚フィードバック）」は、攻撃が当たったときなどに
入れると効果的**です。Capacitor に標準のプラグインがあり、
数行で追加でき、**「アプリらしさ」の説得力になります**。

## 6. 推奨

> ## **A. Capacitor を推奨します。**

### 理由

**1. 5,324行すべてがそのまま動きます**

React Native なら約3,000行を書き直します。Flutter なら全部です。
**いま動いているものを壊さない**という Phase 0 の方針に、最も忠実です。

**2. 書き直している間、ゲームが遊べなくなる期間がありません**

これは軽くない点です。React Native への移行中は、
**数週間〜数か月、誰も遊べない未完成の状態**が続きます。
その間に気力が尽きれば、すべてが無駄になります。

**3. 学習の負担が最も小さい**

プログラミングを始めたばかりの状況で、
React・React Native・Animated を同時に習得するのは現実的ではありません。

**4. 速度は問題になりません**

このゲームは**ターン制**です。1秒間に60回の描画を求められる
アクションゲームではありません。いまの速度で十分です。

**5. あとから変えられます**

**ロジックとデータの2,570行は画面に依存していません。**
将来どうしても React Native が必要になっても、
**その49%はそのまま持っていけます。**
Capacitor を選ぶことは、他の道を閉ざしません。

### React Native を選ぶべき場合

次のいずれかに当てはまるなら、Bを検討する価値があります。

- 1秒間に60回の描画が必要な演出を入れたい
- 端末の機能を深く使いたい（カメラ・AR・Bluetoothなど）
- 今後も長く開発を続け、**学習そのものに時間を投資できる**
- Apple の 4.2 での差し戻しを**絶対に避けたい**

**いまの計画（RPGをストアに出す）には、いずれも当てはまりません。**

## 7. 推奨する進めかた（段階を分ける）

いきなりアプリ化しません。**戻れる順番**で進めます。

| 段階 | 内容 | 得られるもの |
|---|---|---|
| **① Web版を仕上げる** | STEP 10・12・13 の修正 | **これ自体が公開物になる** |
| **② PWA にする** | `manifest.json` と Service Worker | ホーム画面に追加できる。**Capacitorの前提が揃う** |
| **③ Android 版を出す** | Capacitor → Google Play | **費用25ドル（買い切り）・審査が緩やか** |
| **④ iOS 版を出す** | Capacitor → App Store | 費用99ドル/年・**Macが必要** |

**③ を先にする理由**：
- Google Play は**登録25ドル・買い切り**、Apple は**99ドル・毎年**
- Google Play の審査は Apple より通りやすい
- **Macが無くてもAndroid版は作れます**
- ここで「アプリとして動く」ことを確かめてから、iOSに進めます

> ⚠ **④には Mac が必要です。** iOS向けのアプリは、
> Apple の Xcode（Macでしか動きません）でしか作れません。
> Macをお持ちでない場合、ここが実質的な壁になります。
> **先にご確認ください。**
