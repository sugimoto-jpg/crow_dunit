# キャラクター画像の作り方

AI画像生成で素材を作り、`assets/characters/` に置くだけでキャラクターが変わります。
**コードは触りません。**

---

## 手順

1. 下の指定文をコピーして、画像生成AIに入れる
2. 出てきた画像の**背景を透明にする**（多くの生成AIは「透過PNG」を指定できます）
3. 指定のサイズに整える
4. 指定のファイル名で `assets/characters/...` に置く
5. `npm run art` を実行（一覧を作り直す）
6. `npm test` で壊れていないか確認

**1枚から始められます。** 置いていないキャラは今までの絵のままです。

---

## すべてのキャラに共通する指定

生成AIに毎回この文を含めてください。**これが世界観の統一そのものです。**

```
日本のスマホRPG向けの2Dアニメ風キャラクターイラスト。
セルシェーディング、くっきりした黒の輪郭線、影は2〜3段階のみ。
彩度はやや控えめで落ち着いた色。けばけばしくしない。
全身を描く。体は右を向く。直立した待機の姿勢。
背景は完全な透明（アルファチャンネルあり）。
影や地面は描かない。
キャラクターの輪郭のふちを一段明るくして、暗い背景でも沈まないようにする。
足の裏を画像の下端にそろえる。上下左右に少し余白をとる。
過度な露出はしない。全年齢向け。
```

**避けるもの**（生成AIの「除外」欄に入れてください）

```
写真風、3DCG、厚塗り、背景、地面、影、枠、文字、署名、
体の一部が切れている、複数人、過度な露出
```

## 画像を置いたあとに必ず実行

```bash
npm run art     # 画像の一覧を作り直す
npm test        # 壊れていないか確かめる
```

`npm run art` を忘れると、置いた画像は使われません。

---

## うまくいかないとき

| 症状 | 原因 |
|---|---|
| 置いたのに絵が変わらない | `npm run art` を忘れている |
| 絵が変わらない（実行済み） | ファイル名か置き場所が違う。`npm run art` の出力に「読み飛ばした」と出ます |
| 背景が黒や白の四角で出る | 透過されていない。透過PNG/WebPで書き出す |
| 敵が逆を向く | 敵は**右向き**で作る（表示時に反転します） |
| 宙に浮いて見える | 足の裏が画像の下端に付いていない |
| 端が切れる | 余白が足りない。上下左右に3%とる |
